# 🎬 Boardy QA Demo Workflow

## 📋 Demo Script: Paste → Analyze → Insights

### 🎯 Scene 1: Launch & Status Check
```
1. Open Boardy QA Analyzer
2. See "🔧 System Status" section showing:
   - ✅ API Ready - Full Analysis Available
   - 🤖 Rules Engine: 5 Rules Active
   - 📊 Configuration: Optimized
   - ⚡ Performance: Ready
```

### 📝 Scene 2: Paste Problematic Conversation
```
1. Click "📋 Load Sample" or paste:
   [11/20/25, 8:23:03 PM] Boardy: I am here and I cannot help with that specific request. As an AI assistant, I have limitations in my capabilities.
   [11/20/25, 8:23:15 PM] Jurate: Can you help me?
   [11/20/25, 8:23:20 PM] Boardy: i am unable to provide the assistance you need. i do not have access to those resources.
   [11/20/25, 8:23:25 PM] Jurate: What can you do?
   [11/20/25, 8:23:30 PM] Boardy: I cannot read files or images you attach here, so I cannot open the deck directly.

2. Observe the conversation has multiple quality issues:
   - "I cannot" statements (robotic)
   - "As an AI assistant" (breaks conversation flow)
   - Lowercase "i" (unprofessional)
   - Multiple limitations mentioned
```

### 🔍 Scene 3: Real-Time Analysis
```
1. Click "🔍 Analyze Conversation"
2. Watch the analysis process:
   - API call in real-time
   - Processing indicator
   - Results appear instantly

3. Analysis Results Show:
   📊 Statistics:
   - Total Messages: 5
   - Total Failures: 6
   - Failure Rate: 40%
   - Rules Run: 5

   🎯 Severity Breakdown:
   - High: 3 violations
   - Medium: 2 violations
   - Low: 1 violation
```

### 💡 Scene 4: Detailed Violation Insights
```
Each violation shows:

🔍 What's Wrong:
"The assistant is using the phrase 'I cannot' which is overly formal and robotic."

⚠️ Why It Matters:
"Using overly formal language like 'I cannot' makes the conversation feel less natural 
and more like interacting with a machine rather than a helpful assistant."

💡 How to Fix:
"Replace 'I cannot' with more natural, helpful alternatives like 'I'm not able to', 
'I don't have access to', or better yet, explain what you CAN do instead."

📝 Example:
❌ Bad: "I cannot help with that specific request."
✅ Good: "I'm not able to help with that specific request, but I can assist you with..."
```
